# Security Policy

## Supported Versions

Security updates are provided only for the latest release of this research code.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

To report a security issue, please email mustansar.fiaz@ibm.com with a description of the issue, the steps you took to create the issue, affected versions, and if known, mitigations for the issue. Please do **not** open a public GitHub issue for security problems. We will acknowledge receiving your email within 3 working days. This project follows a 90 day disclosure timeline.
